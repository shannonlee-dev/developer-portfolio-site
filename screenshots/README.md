# 화면 예시 이력

`desktop.png`, `mobile.png`, `dark-mode.png`는 최초 제출 커밋 `f248fc2`에 함께 추가된 이미지입니다. 당시 HTML의 Home/About/Skills/Projects/Contact, Dark/Light, STATE FLOW 라벨과 일치합니다. 정확한 촬영 시각과 촬영 환경 버전은 저장소에 남아 있지 않으며 커밋은 촬영 날짜를 의미하지 않습니다.

현재 코드는 한국어 메뉴·테마·상태 흐름 라벨을 사용합니다. 이 이미지들은 과거 레이아웃과 테마 예시로 보존하며 현재 구현 검증 자료로 사용하지 않습니다.

## 현재 화면 확인

1. 저장소 루트에서 `make run`으로 정적 서버를 실행합니다.
2. 로컬 페이지를 데스크톱과 모바일 화면 크기로 열어 메뉴·테마·카드·문의 오류 표시를 확인합니다.
3. 외부 요청 없이 확인하려면 브라우저 개발자 도구에서 GitHub 요청을 로컬 고정 응답으로 대체하고 문의 전송은 차단합니다.
4. 새 이미지를 추가할 때 촬영 커밋, 브라우저 버전, viewport, 테마, 외부 요청 모의 여부를 이 문서에 함께 기록합니다.

현재 자동 테스트는 실제 HTML과 DOM 이벤트를 검사하며 화면 크기별 배치나 실제 외부 연동 결과는 검사하지 않습니다.
